# Настольная версия

Приложение для Windows поверх веб-версии. Внутри — тот же интерфейс проверки и тот же порядок чтения (вырезание строк, перечтение мест, выноски, размеры), но OCR выполняет локальный процесс: модели PaddleOCR в нативном ONNX Runtime. Файлы не покидают компьютер: сеть в приложении закрыта.

Веб-версия от этого каталога не зависит: `npm run build`, `npm start` и `npm test` в корне репозитория работают как раньше, `src/` не изменён.

Зачем это сделано и как устроено — [docs/desktop-spike/ADR.md](../docs/desktop-spike/ADR.md). Что измерено и что из этого следует — [docs/desktop-spike/RESULTS.md](../docs/desktop-spike/RESULTS.md).

## Установка и запуск

Нужен Node.js 22.12 или новее.

```powershell
cd label-check
npm install              # веб-версия и инструменты сборки (если ещё не установлены)
cd desktop
npm install              # Electron и onnxruntime-node
npm run models           # модели локального OCR: три скачиваются (~160 МБ), две берутся из ../assets/models
npm start                # сборка страниц и запуск окна
```

## Окно

- **Проверка** — обычный интерфейс сайта: загрузите требования и макет, проверка начнётся сама. Читают движки, выбранные в списке «Чтение».
- **Сравнение с веб-версией** — откройте «Один файл — оба метода», выберите требования и макет, нажмите «Проверить и сравнить». Файл пройдёт через настольный режим и через сайт как есть; по каждому разделу видны оба вывода, оба чтения с выделенными отличиями, размеры и вырезы макета.
- **Веб-версия как есть** — сайт без изменений, для сверки.

Список «Чтение»:

| Режим | Кто читает | Когда выбирать |
|---|---|---|
| строгое (по умолчанию) | локальный движок, второе мнение — Tesseract.js | не пропустить отличие важнее, чем число разделов, подтверждённых автоматически. На трёх листах поймал все 11 настоящих расхождений; ложных тревог 7 из 27 |
| спокойное | Tesseract.js, второе мнение — локальный движок | результат как у сайта (ложных тревог 1 из 27), памяти нужно меньше |

Одна проверка занимает 1–1,5 минуты и до 3,6 ГБ памяти.

## Команды

| Команда | Что делает |
|---|---|
| `npm start` | собирает `build/` и открывает окно |
| `npm start -- --primary=tesseract --second=local` | то же с другими движками по умолчанию |
| `npm run build` | только сборка: копия веб-версии и страница с подменяемыми движками в `build/web`, страница оболочки в `build/desktop` |
| `npm test` | проверки формата результата, пиксельных функций, метрик и связки со сверкой |
| `npm run models` | скачивает и распаковывает модели, сверяя SHA-256 с `models/manifest.json` |
| `npm run bench` | методы на каждом листе из `bench/corpus.json`, каждый запуск в своём процессе приложения; чтения, время и память — в `bench/out/` |
| `npm run bench -- --sheets=rose --methods=baseline,lab-local-tesseract` | то же для части листов и методов |
| `npm run score` | считает точность сохранённых чтений по разметке `bench/truth/` и пишет `../docs/desktop-spike/results-tables.md`; OCR не запускает. `-- --quick` — без проверки на изменённом Word |
| `npm run grid` | один локальный движок на вырезах этикеток: все сочетания детектора, модели чтения и увеличения |
| `npx electron . --demo=rose` | окно с уже выбранными файлами листа из корпуса; сохраняет снимки окна в `bench/out/` |
| `npm run package` | приложение в `out/LabelCheckDesktop-win32-x64/` (982 МБ, без установщика и подписи) |

Методы для `--methods`: `baseline` — сайт как есть; `lab-<первый>-<второй>` — порядок чтения сайта с движками `tesseract`, `local`, `web` (PaddleOCR в WASM), `none`; `local` — упрощённый локальный метод без вырезания строк и размеров.

Макеты «Сан Ремино» в репозиторий не входят. Сценарии ищут их в каталоге из переменной `LABEL_CORPUS_DIR` (по умолчанию — «Загрузки» пользователя) под именами из `bench/corpus.json`.

Другие модели: `npm start -- --det=PP-OCRv5_mobile_det --rec=cyrillic_PP-OCRv5_mobile_rec`.

## Устройство

```
src/main.mjs                главный процесс: окно, app://, запрет сети, процесс OCR, режимы --bench и --demo
src/preload.cjs             мост window.desktop: recognize, lines, cancel, info, memory
src/ocr/worker.mjs          процесс OCR (utilityProcess), очередь заданий
src/ocr/engine.mjs          поиск строк, чтение, слова и символы с местом на изображении
src/ocr/imaging.mjs         пиксельные функции без Canvas
shared/ocr-result.mjs       единый формат результата OCR, порядок чтения, перевод уверенности
renderer/lab/tesseract.js   встаёт на место tesseract.js в коде сайта
renderer/lab/secondary-ocr.js  встаёт на место второго движка сайта
renderer/host.js            окно: вкладки, запуск, сравнение
renderer/compare.js         вывод метода о тексте раздела, пословное сравнение чтений
renderer/local-pipeline.js  упрощённый локальный метод (только для замеров)
bench/                      корпус, разметка, сценарии сравнения и подсчёта
models/manifest.json        модели и их контрольные суммы (сами модели в git не входят)
```

## Ограничения

- Движки подставляются под код сайта при сборке. Проходы сайта подобраны под Tesseract; локальному движку часть из них мешает (см. RESULTS, «Откуда ложные тревоги»).
- Отмена — перезагрузка страницы проверки.
- Нет установщика, подписи кода и обновлений. В сборку попадает `onnxruntime-node` для всех платформ и все три детектора.
- Результаты не сохраняются: закрытие окна их стирает. Отчёт скачивается кнопкой сайта «Скачать отчёт».
