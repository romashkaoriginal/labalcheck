# Контроль маркировки

Локальное приложение для сверки контрэтикетки с Word. Документы обрабатываются в браузере и не отправляются на сервер. В комплекте образец «Сябры. Чистая» 0,7 л.

## Запуск

```powershell
npm install
npm run build
npm start
```

Адрес: http://127.0.0.1:4173

После изменения исходников повторите `npm run build`. `npm test` проверяет сравнение текста и применение требований.

## Работа

1. Загрузите DOCX с таблицей: раздел, требования, текст. Дополнительные параграфы после `***` также становятся требованиями.
2. Загрузите PDF либо изображение. Нажмите «Область»: макет откроется в большом окне. Обведите этикетку, увеличьте изображение, подвиньте рамку или поправьте её маркерами. Кнопка «Отменить» возвращает предыдущее выделение; «Использовать область» применяет результат. Затем задайте физический размер этикетки и подтвердите масштаб.
3. Запустите распознавание. Для сложного текста используйте кнопку «Текст» и выделяйте небольшие фрагменты. Текстовый слой PDF используется, если присутствует; растровый PDF распознаётся локальным Tesseract.js. Вращение на 90° дополнительно проверяет вертикальные надписи.
4. Сверьте текст по оригиналу. Кнопка «Измерить» открывает тот же увеличенный редактор для выделения видимой высоты букв и знаков. Можно внести достоверные измерения вручную. Даты требуют образца фактической печати.
5. Подтвердите разделы и скачайте HTML-отчёт. Его можно распечатать в PDF.

Проверка остаётся незавершённой, пока не подтверждены все разделы и масштаб. Совпадение OCR само по себе не согласовывает макет. Размытые изображения, технические подписи, точность границ и выбранный масштаб влияют на измерения. Правила взяты из загруженного Word; юридическую актуальность система не определяет.

Состояние живёт в текущей вкладке. При перезагрузке проверки сбрасываются. Хранилища проектов и совместного согласования пока нет.

## Vercel

Приложение статическое: Build Command `npm run build`, Output Directory `dist`. Публикация в текущей задаче не выполняется. До публикации настройте доступ для сотрудников: `assets` содержит документы образца.
