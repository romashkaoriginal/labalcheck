# Контроль маркировки

Локальное приложение для сверки контрэтикетки с Word. Документы обрабатываются в браузере и не отправляются на сервер. В комплекте образец «Сябры. Чистая» 0,7 л.

## Запуск

```powershell
npm install
npm run build
npm start
```

Адрес: http://127.0.0.1:4173

После изменения исходников повторите `npm run build`. `npm test` проверяет сравнение текста и применение требований.

## Работа

1. Загрузите DOCX с таблицей: раздел, требования, текст. Параграфы после `***` также становятся требованиями.
2. Загрузите PDF либо изображение. Автоматическая проверка запускается после загрузки: вручную выделять области не нужно.
3. Сайт ищет пунктирные контуры высечки, выбирает макет по совпадению с Word, распознаёт четыре ориентации и автоматически разделяет текст по пробелам между блоками. Если контур не определён, анализируется вся страница, включая технические подписи. Текстовый слой PDF дополняет OCR.
4. Нажмите на требование: соответствующие слова подсветятся на макете. Точные и частичные совпадения различаются. Размеры с `≈` — оценки по видимым символам OCR и физической геометрии PDF при печати 1:1. Изображение без физического масштаба не даёт миллиметров; кегль PDF не выдаётся за высоту букв.
5. Сверьте спорные результаты и подтвердите разделы. Скачайте HTML-отчёт для печати в PDF. В многостраничном PDF каждая страница проверяется при переключении; отчёт относится к текущей странице.

Автоматическое совпадение не согласовывает макет. Сложные шрифты и плотный текст могут давать ошибки OCR. Знаки, образец даты, читаемость, неизвестные границы и неоднозначные измерения остаются на проверке специалиста. При нескольких этикетках на странице выбирается один наиболее подходящий контур. Правила берутся из Word, юридическую актуальность система не определяет.

Состояние живёт в текущей вкладке. При перезагрузке проверки сбрасываются. Хранилища проектов и совместного согласования пока нет.

## Vercel

Приложение статическое: Build Command `npm run build`, Output Directory `dist`. Репозиторий подключён к Vercel пользователем; push в `main` запускает сборку, если включено автоматическое развёртывание. `assets` содержит документы образца.
